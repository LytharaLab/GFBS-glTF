# GFBS:glTF 1.0 API

依赖范围建议写为：

```toml
versionRange = "[1.0.0,2.0.0)"
```

## 加载 glTF、GLB 与 OBJ

客户端模型管理器会根据后缀选择导入器，并自动处理异步缓存、并发请求、资源包重载与 GPU 资源失效：

```java
CompletableFuture<GltfAsset> future = ClientGltfApi.models().load(
    ResourceLocation.fromNamespaceAndPath("example", "models/reactor.glb")
);
```

`.gltf`、`.glb` 和 `.obj` 已内建。OBJ 同目录的 `mtllib` 与 `map_Kd` 会通过 Minecraft 资源系统解析，禁止绝对路径、命名空间跳转和 `..`。

### 注册自定义格式

自定义导入器必须把文件转换成统一的不可变 `GltfAsset`：

```java
public final class MyImporter implements ModelImporter {
    @Override
    public Collection<String> extensions() {
        return List.of("mymodel");
    }

    @Override
    public GltfAsset load(ResourceLocation source, GltfResolver resolver)
        throws IOException {
        try (InputStream input = resolver.open(source)) {
            // Parse and return a validated GltfAsset.
        }
    }
}

ModelImporters.register(new MyImporter());
```

`register` 不会静默覆盖相同后缀；明确需要替换时使用 `ModelImporters.replace`。资源包重载后，管理器仍会调用当前注册的导入器。

## 实例

```java
GltfInstance instance = new GltfInstance(asset);
instance.animations().play("idle", PlaybackOptions.loop());
instance.setNodeVisible("service_panel", false);
instance.update(deltaSeconds);
```

实例拥有独立的动画、场景、节点显隐、渲染选项和碰撞器。实例不再使用时，如果启用过碰撞，应关闭：

```java
instance.close();
```

## 原版实体 Shader 渲染

常规调用保持兼容：

```java
GltfRenderer.render(instance, poseStack, buffers, packedLight, packedOverlay);
```

1.0 的无光影路径固定使用 Minecraft `NEW_ENTITY` 与原版实体 Shader，不加载 GFBS 自研 PBR Shader，也不需要 Embeddium。

检测到 Oculus/Iris 光影包实际启用时，渲染几何仍走实体 RenderType，但会延迟生成 LabPBR normal/specular 伴随纹理。关闭光影后，新加载模型不会产生这些纹理。

### 剔除上下文

逐 primitive 视锥剔除、最大距离和遮挡查询需要帧上下文：

```java
GltfRenderContext context = new GltfRenderContext(
    projectionMatrix,
    frustum,
    camera
);

GltfRenderer.render(
    instance,
    poseStack,
    buffers,
    packedLight,
    packedOverlay,
    context
);
```

默认开启静态 primitive 视锥剔除。蒙皮或 morph 几何不会使用可能错误的静态包围盒剔除。

```java
instance.renderOptions()
    .frustumCulling(true)
    .maxRenderDistance(192.0)
    .occlusionCulling(true);
```

遮挡查询默认关闭。启用后，结果按实例 UUID、节点、mesh 和 primitive 隔离，并异步读取上一轮可用结果。

## 自定义 RenderType

全实例覆盖：

```java
instance.renderOptions().renderType(myRenderType);
```

按节点名覆盖：

```java
instance.renderOptions().nodeRenderType("energy_ring", myRenderType);
```

按零件与材质动态选择：

```java
instance.renderOptions().renderTypeFactory((part, material) -> {
    if (part.nodeName().startsWith("glass")) return glassType;
    return null; // null 表示继续使用默认实体 RenderType
});
```

也可过滤单个 primitive：

```java
instance.renderOptions().partFilter(part -> part.materialIndex() != hiddenMaterial);
```

自定义类型默认会校验 `DefaultVertexFormat.NEW_ENTITY`，并要求三角几何使用 `QUADS`/`TRIANGLES`、线几何使用 `LINES`。用内建 builder 可避免格式不匹配：

```java
RenderType additive = GltfRenderTypes.builder("reactor_glow")
    .texture(glowTexture)
    .additiveBlend()
    .cull(false)
    .writeDepth(false)
    .sortOrder(GltfRenderTypes.ORDER_TRANSLUCENT)
    .build();
```

## 碰撞

碰撞器默认关闭。其变换是模型局部空间到世界空间的矩阵，必须由持有实例的实体、方块实体或系统更新：

```java
instance.collision()
    .attach(level)
    .transform(new Matrix4f().translate(worldX, worldY, worldZ))
    .enable("collision");
```

`enable("collision")` 选择同名节点；`includeDescendants(true)` 会包含子树。默认会隐藏显式选择的碰撞节点，避免专用 collider mesh 被渲染：

```java
instance.collision().options()
    .hideColliderNodes(true)
    .includeDescendants(true);
instance.collision().markSelectionDirty();
```

三档模式：

- `BOUNDS`：每个 primitive 一个变换后的 AABB，最快、最粗。
- `FAST`：局部三角面体素化一次并缓存，动画时只变换合并后的盒子。
- `PRECISE`：先应用当前 morph、skin、节点与实例世界变换，再体素化；大模型自动在单独守护线程重建。

```java
instance.collision().options()
    .mode(CollisionMode.PRECISE)
    .precision(0.125f)
    .solid(true)
    .maxVoxels(24_000_000)
    .maxBoxes(40_000);
instance.collision().markDirty();
```

`instance.update(deltaSeconds)` 会在动画更新后刷新启用的碰撞。射线检测可用：

```java
Vec3 hit = GltfCollisionManager.clip(level, from, to);
```

## 0.3 迁移

- 加载、动画 mixer、节点显隐、场景选择和网络同步调用保持兼容。
- 删除 `embeddium` 强制依赖。
- 不再存在 GFBS standalone PBR Shader；无光影材质表现遵循原版实体 Shader。
- 需要逐零件剔除时使用带 `GltfRenderContext` 的重载。
- 碰撞为 opt-in；只有调用 `enable` 后才向实体移动碰撞注入形状。
