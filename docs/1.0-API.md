## Requirements and dependency declaration

GFBS: glTF 1.1 targets:

| Component | Version |
| --- | --- |
| Minecraft | `1.20.1` |
| Minecraft Forge | `47.4.21` |
| Java | `17` |
| Mod ID | `gfbs_gltf` |
| API line | `1.x` |

Declare the mod dependency in `META-INF/mods.toml`:

```toml
[[dependencies.your_mod_id]]
modId = "gfbs_gltf"
mandatory = true
versionRange = "[1.1.1,2.0.0)"
ordering = "AFTER"
side = "BOTH"
```

Add the GFBS: glTF JAR to the consuming project's ForgeGradle dependencies using the repository or local dependency arrangement used by that project. Do not bundle a second copy inside another mod unless the distribution model explicitly requires it.

Client-only entry points are annotated with `@OnlyIn(Dist.CLIENT)`. Do not reference them from classes that can load on a dedicated server.

## Asset locations and supported formats

Models are addressed with `ResourceLocation` and loaded through Minecraft's resource manager.

For this resource ID:

```java
ResourceLocation.fromNamespaceAndPath("example", "models/reactor.glb")
```

place the file at:

```text
src/main/resources/assets/example/models/reactor.glb
```

Built-in importers support:

- `.gltf`
- `.glb`
- `.obj`

The glTF importer supports glTF 2.0 model data, GLB containers, external resources, data resources, sparse accessors, multiple scenes, skins, morph targets, animations, two UV sets, vertex colors, tangents, and all glTF primitive modes.

The OBJ importer supports OBJ geometry, MTL material libraries, diffuse colors, opacity, and `map_Kd` textures. Faces are triangulated during import.

External model resources are resolved inside the source model's namespace. Absolute paths, namespace changes, parent-directory traversal, and unsafe references are rejected.

Models that declare an unsupported required glTF extension fail to load. GFBS: glTF 1.x accepts `KHR_mesh_quantization` as a required extension.

## Loading models

### Asynchronous client loading

Use `ClientGltfApi.models()` for normal client integrations:

```java
ResourceLocation id = ResourceLocation.fromNamespaceAndPath(
    "example",
    "models/reactor.glb"
);

CompletableFuture<GltfAsset> future = ClientGltfApi.models().load(id);
```

The client manager:

- Loads on Minecraft's background executor.
- Deduplicates concurrent requests for the same resource ID.
- Caches completed assets.
- Cancels stale loads during resource reload.
- Invalidates associated GPU data when requested.

Handle completion explicitly:

```java
ClientGltfApi.models().load(id).whenComplete((asset, error) -> {
    if (error != null) {
        LOGGER.error("Unable to load model {}", id, error);
        return;
    }

    GltfInstance instance = new GltfInstance(asset);
    // Store the instance on the owning client object.
});
```

Query the cache without starting a load:

```java
Optional<GltfAsset> loaded = ClientGltfApi.models().getIfLoaded(id);
```

Invalidate one model and its GPU cache entry:

```java
ClientGltfApi.models().invalidate(id);
```

### Synchronous side-neutral glTF loading

`GltfLoader` provides synchronous decoding for `.gltf` and `.glb` when the caller supplies a resolver:

```java
GltfAsset asset = GltfLoader.load(modelId, location -> {
    return resourceManager.getResource(location)
        .orElseThrow(() -> new FileNotFoundException(location.toString()))
        .open();
});
```

Set a custom per-resource byte limit when loading untrusted or unusually large assets:

```java
GltfAsset asset = GltfLoader.load(
    modelId,
    resolver,
    64L * 1024L * 1024L
);
```

The default glTF resource limit is 256 MiB per opened resource. The loader also applies structural and allocation limits before constructing runtime data.

### Loading through the importer registry

`ModelImporters.load` selects an importer by filename extension:

```java
GltfAsset asset = ModelImporters.load(modelId, resolver);
```

Use this entry point when code should accept built-in and third-party model formats.

## Static Forge block and item models

GFBS: glTF registers a Forge geometry loader named `gfbs_gltf:gltf`. It is intended for blocks
and items whose glTF model is static: the selected scene is baked into Forge's normal
`BakedModel`/`BakedQuad` representation during resource loading, so no per-frame animation runtime
is involved.

Example `assets/example/models/block/console.json`:

```json
{
  "loader": "gfbs_gltf:gltf",
  "model": "example:models/block/console.glb",
  "textures": {
    "particle": "example:block/console",
    "material_0": "example:block/console"
  },
  "material_textures": {
    "0": "#material_0"
  },
  "render_type": "minecraft:cutout",
  "scale": 1.0,
  "translation": [0.0, 0.0, 0.0],
  "flip_v": false,
  "shade": true,
  "automatic_culling": false
}
```

Supported loader members:

| Member | Type | Default | Purpose |
| --- | --- | --- | --- |
| `model` | resource location | required | `.gltf` or `.glb` resource to bake. |
| `scene` | integer | asset default | Scene index to bake. |
| `scale` | number or three-number array | `1.0` | Import scale; all components must be finite and non-zero. |
| `translation` | number or three-number array | `[0,0,0]` | Import translation in block-model coordinates. |
| `flip_v` | boolean | `false` | Flip base-color V texture coordinates. |
| `shade` | boolean | `true` | Enable vanilla directional face shading. |
| `automatic_culling` | boolean | `false` | Cull faces only when all vertices lie on the matching block boundary. |
| `material_textures` | object | `{}` | Map a glTF material index or exact material name to a declared Forge texture slot/reference. |

The model JSON must declare every atlas texture. Resolution tries `material_textures`, then
`material_<index>`, the exact glTF material name, `texture`, and finally `particle`. Normal Forge
fields such as `render_type`, `ambientocclusion`, root transforms, and component visibility remain
available through the geometry baking context.

The default node transforms, default morph weights, and rest-pose skin matrices are baked.
Animation clips are deliberately not evaluated; use `GltfInstance` and `GltfRenderer` for animated
content. Triangle, triangle-strip, and triangle-fan primitives are supported. Points and line
primitives fail model loading with a diagnostic instead of being silently corrupted. Models are
cached for the active resource manager and the cache is cleared on resource reload.

## Working with assets and instances

### Immutable assets

`GltfAsset` is immutable after construction. It contains validated lists of:

- Scenes
- Nodes
- Meshes
- Materials
- Textures
- Skins
- Animation clips
- Used and required extension names

Common queries:

```java
ResourceLocation id = asset.id();
int defaultScene = asset.defaultScene();
List<String> animations = asset.animationNames();
Optional<AnimationClip> idle = asset.animation("idle");
```

Unnamed animations receive stable generated names such as `animation_0`. Duplicate names receive suffixes such as `walk#1`.

Array-valued model accessors return defensive copies. Store indexes rather than attempting to mutate model objects.

### Per-use instances

Create a separate `GltfInstance` for each independently animated or configured use of an asset:

```java
GltfInstance instance = new GltfInstance(asset);
```

An instance owns:

- A unique UUID.
- The selected scene.
- Whole-instance visibility.
- Per-node visibility.
- An independent `AnimationController` and pose.
- Independent `GltfRenderOptions`.
- An independent `GltfCollider`.

Do not share one instance between objects that require different animation times, hidden parts, render settings, or collision transforms.

### Updating

Advance animation and enabled collision with elapsed seconds:

```java
instance.update(deltaSeconds);
```

`deltaSeconds` must be finite. Use frame time for frame-driven animation or a fixed tick delta when tick-driven behavior is intentional.

### Scene selection

```java
instance.setScene(sceneIndex);
int selected = instance.scene();
```

The scene index must exist in `asset.scenes()`.

### Visibility

Hide the entire instance:

```java
instance.setVisible(false);
```

Hide one node by index:

```java
instance.setNodeVisible(nodeIndex, false);
```

Hide every node with an exact name match:

```java
int matches = instance.setNodeVisible("service_panel", false);
```

A hidden node suppresses its complete child subtree. Restore all node visibility with:

```java
instance.resetNodeVisibility();
```

Collision nodes configured with `hideColliderNodes(true)` are also suppressed by the renderer while selected for collision.

### Closing

`GltfInstance` implements `AutoCloseable`:

```java
instance.close();
```

Closing disables and unregisters its collision source. Closing is important for instances that enabled collision or are replaced repeatedly.

## Rendering

### Basic rendering

Render with a supplied `MultiBufferSource`:

```java
GltfRenderer.render(
    instance,
    poseStack,
    buffers,
    packedLight,
    packedOverlay
);
```

A convenience overload can obtain the normal rendering path internally:

```java
GltfRenderer.render(
    instance,
    poseStack,
    packedLight,
    packedOverlay
);
```

The caller controls placement through `PoseStack`:

```java
poseStack.pushPose();
poseStack.translate(x, y, z);
poseStack.mulPose(rotation);
poseStack.scale(scale, scale, scale);

GltfRenderer.render(instance, poseStack, buffers, packedLight, packedOverlay);

poseStack.popPose();
```

Do not mutate a shared `PoseStack` without balancing `pushPose()` and `popPose()`.

### Rendering policy

GFBS: glTF 1.1 uses Minecraft entity RenderTypes, `DefaultVertexFormat.NEW_ENTITY`, and native
`TRIANGLES` submission for its normal path. Triangle strips and fans are expanded to true
triangles; no vertex is duplicated to impersonate a quad.

Without an active shader pack:

- Base-color textures and material factors are rendered through Minecraft entity shaders.
- World light and overlay values come from the renderer call.
- No standalone GFBS PBR shader is loaded.

With an active Oculus or Iris shader pack:

- Geometry remains on the entity rendering path.
- LabPBR normal and specular companion textures are created lazily when the compatibility bridge is available.
- GFBS detects the shadow pass and renders triangle geometry through depth-writing solid or cutout entity RenderTypes.
- Color-pass frustum, maximum-distance, and occlusion culling are bypassed for shadow casters.
- Custom RenderType overrides are ignored during the shadow pass so translucent or depth-disabled states cannot erase the caster.
- The shader pack owns its lighting, shadow resolution, distance, filtering, and deferred targets.

Oculus and Iris are optional runtime integrations, not hard dependencies.

For entity and block-entity renderers, pass through the `MultiBufferSource` supplied by Minecraft:

```java
GltfRenderer.render(instance, poseStack, buffers, packedLight, packedOverlay);
```

The convenience overload remains supported, but forwarding the caller-owned buffer is preferred
because it preserves the active renderer's batching and pass ownership.

### Lighting and alpha

Configure lighting and whole-instance alpha through `GltfRenderOptions`:

```java
instance.renderOptions()
    .light(GltfRenderOptions.LightMode.WORLD)
    .alpha(0.85f);
```

Available lighting modes:

- `WORLD`: use the supplied packed light.
- `FULLBRIGHT`: render with full block and sky light.

Alpha must be between `0.0` and `1.0`.

### Shadow casting

Shadow casting is enabled by default:

```java
instance.renderOptions().castShadows(true);
```

Disable it for effects that should never contribute to an Oculus/Iris shadow map:

```java
instance.renderOptions().castShadows(false);
```

This option controls shader-pack shadow maps. It does not create or remove Minecraft's vanilla
entity blob shadow.

### Face culling

```java
instance.renderOptions().cull(GltfRenderOptions.CullMode.AUTO);
```

Modes:

- `AUTO`: follow the material's double-sided setting.
- `FORCE_CULL`: enable culling for all parts.
- `FORCE_NO_CULL`: disable culling for all parts.

## Render options and culling

### Frame context

Distance culling, primitive frustum culling, and occlusion queries use `GltfRenderContext`:

```java
GltfRenderContext context = new GltfRenderContext(
    projectionMatrix,
    frustum,
    camera
);

GltfRenderer.render(
    instance,
    poseStack,
    buffers,
    packedLight,
    packedOverlay,
    context
);
```

The projection matrix is defensively copied by the context.

### Frustum culling

Primitive frustum culling is enabled by default:

```java
instance.renderOptions().frustumCulling(true);
```

Static primitive bounds are not used for skinning or morph-target geometry when doing so could incorrectly remove animated geometry.

Camera frustum and maximum-distance culling apply only to the color pass. They are deliberately
ignored while Oculus/Iris is rendering a shadow map.

### Maximum render distance

```java
instance.renderOptions().maxRenderDistance(192.0);
```

A distance of `0.0` disables the maximum-distance limit. Distances must be finite and non-negative.

### Occlusion queries

```java
instance.renderOptions().occlusionCulling(true);
```

Occlusion culling is disabled by default. Results are isolated by instance UUID, node, mesh, and primitive. Query results are consumed asynchronously from a previous available result rather than blocking the current draw.

Occlusion query results are never reused for shadow-map rendering.

Use occlusion queries only after profiling. They are most useful for larger static or mostly static parts that are frequently hidden by opaque geometry.

### Part filtering

Filter individual render parts:

```java
instance.renderOptions().partFilter(part -> {
    return part.materialIndex() != hiddenMaterialIndex;
});
```

`GltfRenderPart` exposes:

- `nodeIndex()`
- `nodeName()`
- `meshIndex()`
- `primitiveIndex()`
- `materialIndex()`

Filters run during rendering and should remain cheap and side-effect free.

## Custom RenderTypes

RenderType selection can be overridden at three levels.

### Whole instance

```java
instance.renderOptions().renderType(customType);
```

### Node name

```java
instance.renderOptions().nodeRenderType("energy_ring", customType);
```

Pass `null` to remove one node override:

```java
instance.renderOptions().nodeRenderType("energy_ring", null);
```

### Dynamic part and material selection

```java
instance.renderOptions().renderTypeFactory((part, material) -> {
    if (part.nodeName().startsWith("glass")) {
        return glassType;
    }
    return null;
});
```

Returning `null` continues to the next applicable selection or the default entity RenderType.

Custom RenderTypes affect the color pass only. During an Oculus/Iris shadow pass, GFBS selects its
own depth-writing solid or cutout entity RenderType from the material alpha mode.

Clear all RenderType overrides:

```java
instance.renderOptions().clearRenderTypeOverrides();
```

### Format validation

Custom RenderTypes are validated against:

```java
DefaultVertexFormat.NEW_ENTITY
VertexFormat.Mode.TRIANGLES
```

Validation is enabled by default:

```java
instance.renderOptions().validateRenderTypeFormat(true);
```

Disabling validation is an advanced escape hatch. A mismatched vertex format can corrupt rendering or fail at runtime.

Check compatibility directly:

```java
boolean compatible = GltfRenderTypes.isCompatible(customType);
```

### Built-in entity RenderTypes

```java
RenderType solid = GltfRenderTypes.solid(texture, true);
RenderType cutout = GltfRenderTypes.cutout(texture, false);
RenderType translucent = GltfRenderTypes.translucent(texture, false);
RenderType lines = GltfRenderTypes.lines(texture, true);
```

### Custom builder

```java
RenderType glow = GltfRenderTypes.builder("reactor_glow")
    .texture(glowTexture)
    .additiveBlend()
    .cull(false)
    .lightmap(true)
    .overlay(true)
    .writeColor(true)
    .writeDepth(false)
    .sortOnUpload(true)
    .sortOrder(GltfRenderTypes.ORDER_TRANSLUCENT)
    .build();
```

The builder supports:

- Texture, blur, and mipmap state.
- A custom entity-format-compatible shader supplier.
- No, translucent, or additive blending.
- Culling.
- Lightmap and overlay state.
- Color and depth write masks.
- OpenGL depth function.
- Outline participation.
- Upload sorting.
- Buffer size.
- Explicit render order.
- Native `TRIANGLES` mode.

The builder defaults to `TRIANGLES` and rejects `QUADS`. A quad-mode override would require
padding every glTF triangle with a repeated vertex, creating degenerate geometry and invalid
tangent derivatives. Line primitives continue to use the built-in `LINES` RenderType.

Register an order for an externally constructed compatible type:

```java
GltfRenderTypes.registerSortOrder(customType, GltfRenderTypes.ORDER_CUSTOM);
```

Common order constants are:

| Constant | Value |
| --- | ---: |
| `ORDER_SOLID` | `0` |
| `ORDER_CUTOUT` | `100` |
| `ORDER_CUSTOM` | `500` |
| `ORDER_TRANSLUCENT` | `1000` |

## Animation

Every `GltfInstance` owns an `AnimationController`:

```java
AnimationController animations = instance.animations();
```

### Basic playback

Play once:

```java
animations.play("startup", PlaybackOptions.once());
```

Loop:

```java
animations.play("idle", PlaybackOptions.loop());
```

Custom playback:

```java
PlaybackOptions options = new PlaybackOptions(
    1.25f,
    LoopMode.LOOP,
    0.2f,
    0.0f
);

animations.play("idle", options);
```

`PlaybackOptions` fields are:

- `speed`: finite and non-zero; negative values play backward.
- `loopMode`: `ONCE`, `LOOP`, or `HOLD`. Only `LOOP` wraps; non-looping modes stop at a clip boundary and retain the boundary pose.
- `transitionSeconds`: crossfade duration from the previous state on the same layer.
- `initialTime`: initial clip time in seconds.

Advance playback through `instance.update(deltaSeconds)` or directly through `animations.update(deltaSeconds)` when collision does not need the same update call.

### Playback control

```java
animations.pause();
animations.resume();
animations.seek(1.5f);
animations.stop(true);
```

`stop(true)` removes the base layer and re-evaluates the pose. `stopAll(true)` clears every layer and resets the pose to bind state.

Query base-layer state:

```java
float time = animations.time();
boolean playing = animations.isPlaying();
Optional<AnimationClip> clip = animations.currentClip();
```

### Layers

The base layer name is:

```java
AnimationController.BASE_LAYER
```

Play a named layer:

```java
int nodeCount = asset.nodes().size();

animations.playLayer(
    "upper_body",
    "maintenance",
    PlaybackOptions.loop(),
    1.0f,
    AnimationBlendMode.OVERRIDE,
    AnimationMask.all(nodeCount)
);
```

Layer weights must be between `0.0` and `1.0`.

Available blend modes:

- `OVERRIDE`: interpolate the accumulated pose toward the sampled layer pose.
- `ADDITIVE`: apply the sampled clip's delta from bind pose.

Control a layer:

```java
animations.setLayerWeight("upper_body", 0.6f);
animations.fadeLayer("upper_body", 0.0f, 0.25f);
animations.pauseLayer("upper_body");
animations.resumeLayer("upper_body");
animations.seekLayer("upper_body", 0.5f);
animations.stopLayer("upper_body", 0.2f);
```

Inspect layer snapshots:

```java
Optional<AnimationLayer> layer = animations.layer("upper_body");
List<AnimationLayer> layers = animations.layers();
```

### Masks

Animate every node:

```java
AnimationMask mask = AnimationMask.all(asset.nodes().size());
```

Animate selected node indexes:

```java
AnimationMask mask = AnimationMask.ofNodes(
    asset.nodes().size(),
    leftArmNode,
    rightArmNode,
    toolNode
);
```

A mask's node count must match the asset.

### Events

Register a marker on a clip:

```java
animations.addEvent(
    "startup",
    new AnimationEvent("ignition", 1.35f)
);
```

Listen for events:

```java
AnimationEventListener listener = (layerName, clip, event) -> {
    if (event.name().equals("ignition")) {
        startIgnitionEffect();
    }
};

animations.addEventListener(listener);
```

Remove the listener when the owner is disposed:

```java
animations.removeEventListener(listener);
```

Events fire when playback crosses their time, including loop wrapping and reverse playback.

### Pose access

The evaluated pose is available through:

```java
ModelPose pose = animations.pose();
NodePose nodePose = pose.node(nodeIndex);
```

Pose arrays are mutable runtime state. Do not modify the controller's live pose unless the integration deliberately owns the consequences for rendering and collision.

## Server-authoritative animation synchronization

Synchronization separates server commands from client rendering instances.

### Target keys

Create a stable target key for an entity:

```java
AnimationTargetKey target = AnimationTargetKey.entity(level, entity.getUUID());
```

For a block entity:

```java
AnimationTargetKey target = AnimationTargetKey.blockEntity(level, blockPos);
```

For a custom system:

```java
AnimationTargetKey target = AnimationTargetKey.custom(
    level,
    ResourceLocation.fromNamespaceAndPath("example", "main_reactor")
);
```

A target includes dimension, kind, and stable string ID.

### Server commands

Start playback from the server:

```java
SyncedAnimationState state = ServerAnimations.play(
    serverLevel,
    target,
    "startup",
    1.0f,
    LoopMode.ONCE,
    0.2f
);
```

Control the target:

```java
ServerAnimations.pause(serverLevel, target);
ServerAnimations.resume(serverLevel, target);
ServerAnimations.stop(serverLevel, target);
```

### Client binding

Bind the rendered instance to the same target:

```java
SyncedGltfAnimations.bind(target, instance);
```

Unbind when the renderer or owner is removed:

```java
SyncedGltfAnimations.unbind(target);
```

The client applies the latest known synchronized state to a bound instance. Keep target IDs stable across the server and client representation of the same object.

`SyncedAnimationState` can be stored in NBT with `save()` and restored with `load(CompoundTag)` when custom persistence is needed.

## Custom model importers

### Importer contract

A custom importer converts one or more extensions into a validated immutable `GltfAsset`:

```java
public final class MyModelImporter implements ModelImporter {
    @Override
    public Collection<String> extensions() {
        return List.of("mymodel");
    }

    @Override
    public GltfAsset load(ResourceLocation source, GltfResolver resolver)
        throws IOException {
        try (InputStream input = resolver.open(source)) {
            // Decode, validate, and return a GltfAsset.
            throw new UnsupportedOperationException("Implement importer");
        }
    }
}
```

Register it during mod setup before models using the extension are requested:

```java
ModelImporter importer = new MyModelImporter();
ModelImporters.register(importer);
```

Extensions are normalized to lowercase and may be declared with or without a leading dot.

### Registry behavior

`register` refuses to overwrite another importer for the same extension:

```java
ModelImporters.register(importer);
```

Use `replace` only when replacement is deliberate:

```java
ModelImporters.replace(importer);
```

Remove the exact registered importer instance:

```java
boolean removed = ModelImporters.unregister(importer);
```

Inspect registry state:

```java
Set<String> extensions = ModelImporters.extensions();
boolean supported = ModelImporters.supports(modelId);
Optional<ModelImporter> selected = ModelImporters.find(modelId);
```

The registry is synchronized and can be called by asynchronous model loading. Importers must be safe for concurrent loads unless they serialize internally.

### Importer requirements

A production importer should:

- Resolve every dependent resource through the supplied `GltfResolver`.
- Keep references namespace-local unless the format has a separately reviewed policy.
- Apply size, count, recursion, and allocation limits before allocating large arrays.
- Reject non-finite numeric values and invalid indexes.
- Provide at least one material, using `GltfMaterial.defaultMaterial()` when necessary.
- Construct consistent parent and child node references.
- Validate skin, morph-target, material, UV, and animation references.
- Avoid retaining open streams after `load` returns.
- Throw `IOException` with useful context for decode failures.

## Collision

Collision is disabled by default and configured per instance.

### Enable and attach

Enable the complete model:

```java
instance.collision()
    .attach(level)
    .transform(new Matrix4f().translation(worldX, worldY, worldZ))
    .enable();
```

Enable nodes with exact names:

```java
instance.collision()
    .attach(level)
    .transform(modelToWorld)
    .enable("collision", "walkway_collider");
```

The transform maps model-local coordinates into world coordinates. Update it whenever the owning object moves, rotates, or scales:

```java
instance.collision().transform(modelToWorld);
```

### Selection

Configure whether named node selections include descendants:

```java
instance.collision().options()
    .includeDescendants(true)
    .hideColliderNodes(true);

instance.collision().markSelectionDirty();
```

`hideColliderNodes(true)` hides explicitly selected collider nodes from rendering. It is enabled by default.

Clear named groups and use the complete model:

```java
instance.collision().options().wholeModel();
instance.collision().markSelectionDirty();
```

### Modes

```java
instance.collision().options().mode(CollisionMode.FAST);
```

| Mode | Behavior | Typical use |
| --- | --- | --- |
| `BOUNDS` | One transformed AABB per selected primitive. | Fast broad collision or simple machinery. |
| `FAST` | Voxelize local geometry once, cache boxes, then transform them. | Detailed static geometry and rigid movement. |
| `PRECISE` | Apply the current morph, skin, node pose, and model transform before voxelization. | Animated geometry that needs current-pose collision. |

`PRECISE` rebuilds large meshes on a dedicated daemon executor after the configured triangle threshold.

### Voxel settings

```java
instance.collision().options()
    .precision(0.125f)
    .solid(true)
    .margin(0.01f)
    .maxVoxels(24_000_000L)
    .maxBoxes(40_000)
    .asyncTriangleThreshold(20_000);
```

- `precision`: voxel cell size; smaller values are more detailed and more expensive.
- `solid`: fill the voxelized interior rather than keeping only the surface.
- `margin`: non-negative expansion around generated collision boxes.
- `maxVoxels`: hard voxel-count limit.
- `maxBoxes`: hard merged-box limit.
- `asyncTriangleThreshold`: selected triangle count at which precise rebuilding moves to the collision executor.

Call `markDirty()` after changing inputs that the collider cannot infer:

```java
instance.collision().markDirty();
```

`instance.update(deltaSeconds)` refreshes enabled collision after animation advances.

### Shape and ray clipping

Inspect the current generated collision result:

```java
var collisionShape = instance.collision().shape();
int boxCount = collisionShape.boxCount();
boolean empty = collisionShape.isEmpty();
```

Ray-clip against the instance directly:

```java
Vec3 hit = instance.collision().clip(from, to);
```

Disable and unregister collision:

```java
instance.collision().disable();
```

Closing the instance also disables collision.

## Resource reload and lifecycle

The client model manager is registered as a Minecraft resource reload listener.

On reload it:

- Updates the active resource manager.
- Advances an internal generation counter.
- Cancels stale in-flight loads.
- Clears the CPU asset cache.
- Clears GPU model and texture resources.

A future can be cancelled when a reload occurs during loading. Treat cancellation as a normal lifecycle event rather than an unrecoverable model-format error.

Recommended owner lifecycle:

1. Store the model `ResourceLocation` independently from the loaded asset.
2. Start or restart an asynchronous load when the owner becomes active or resources reload.
3. Replace the old instance only after the new load succeeds.
4. Close the old instance.
5. Do not retain internal GPU objects across reload.

## Threading and error handling

### Client model manager

`ClientGltfApi.models().load` performs file decoding on Minecraft's background executor. Completion callbacks may therefore begin off the render thread.

Do not create or mutate unrelated Minecraft render state inside a background callback. Store decoded state or schedule client-thread work when the integration requires Minecraft thread affinity.

### Rendering

Call `GltfRenderer.render` from the render thread and from a valid Minecraft rendering callback.

### Importers

The importer registry can be used by concurrent loads. Avoid mutable shared parser state or guard it explicitly.

### Collision

Large `PRECISE` collision rebuilds can run on the dedicated GFBS collision executor. Current shapes remain available until a replacement completes.

### Failures

Asynchronous load failures complete the returned future exceptionally and are logged with the resource ID. Always attach an exception handler when missing or malformed assets are possible.

Avoid replacing a working instance with `null` before a reload completes. Keeping the previous instance until a replacement succeeds prevents visible disappearance from transient failures.

## Migration from 0.3

GFBS: glTF 1.x preserves the main 0.3 loading, instance, animation, visibility, scene, rendering, and synchronization concepts while expanding the runtime.

Important changes:

- The mandatory Embeddium dependency has been removed.
- The no-shader path uses Minecraft's original entity shaders instead of a standalone GFBS PBR shader.
- Shader-pack PBR integration is optional and detected at runtime.
- `.obj` and `.mtl` are built in.
- Third-party formats can register `ModelImporter` implementations.
- Render options now include part filters, node-specific RenderTypes, dynamic RenderType factories, maximum distance, and occlusion queries.
- Primitive frustum and occlusion culling require the `GltfRenderContext` render overload.
- Collision is opt-in and owned by each `GltfInstance`.
- `GltfInstance.close()` should be called when collision-enabled instances are discarded.
- Static primitive culling is intentionally avoided for morphing and skinned geometry where bounds could be incorrect.

A minimal 0.3-style render remains valid:

```java
GltfRenderer.render(
    instance,
    poseStack,
    buffers,
    packedLight,
    packedOverlay
);
```

Adopt the context overload only when distance, frustum, or occlusion information is available:

```java
GltfRenderer.render(
    instance,
    poseStack,
    buffers,
    packedLight,
    packedOverlay,
    context
);
```
